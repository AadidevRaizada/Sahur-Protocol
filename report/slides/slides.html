STEP 2 · REQUIREMENTS · EXP 1

What the game must do

FUNCTIONAL · WHAT IT DOES
  • Start a new game or continue a saved one
  • Move with WASD, swing with Space
  • Sahur attacks enemies automatically
  • 3 worlds × 3 rooms + a boss, then the final boss
  • Pick a skill upgrade after every room
  • Auto-save at checkpoints
  • Touch controls on phones
NON-FUNCTIONAL · HOW WELL
  • Performance: smooth play on any screen
  • Portability: desktop and mobile browsers
  • Usability: readable text, clear menus
  • Reliability: keeps running even if saving is blocked
  • Maintainability: content kept in simple data tables

STEP 3 · AGILE NFRs · EXP 2

Quality written as user stories

NFR-US-02Steady framesPERFORMANCE

As a player on a slow device, I want the game to stay fair when it slows down, so that enemies never jump across the screen.

ACCEPTANCE CRITERIA
  1. The game redraws on every screen refresh.
  2. Each update step is at most 33 ms.
